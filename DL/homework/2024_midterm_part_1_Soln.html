Problem 1¶

Find $J$ of the below optimization problem with the following objective function and constraint. ($x,\omega, \omega_0 \in \mathbb{R}^n$)


$$ \begin{align*} J = \;\min_x \quad & \rVert x \lVert_2\\ \\ \text{subject to}\quad & \omega^T x + \omega_0 = 0 \end{align*}$$


Solution

If $x$ is on the line of $\omega_0 + \omega^Tx = 0$, the objective function can be interpreted as the shortest distance $J^{*}$ from origin to the line. We geometrically (or intuitively) know that distance $J$ will be minimal when vector $x$ is orthogonal to the line


$$ \begin{align} \vec x^* & =J^{*}\frac{\vec \omega}{\lVert \omega \rVert} \\ \\ \omega_0 + \omega^Tx & = \omega_0 + \omega^T\left(J^{*}\frac{\omega}{\lVert \omega \rVert}\right) \\ & = \omega_0 + J^{*}\lVert \omega \rVert = 0 \\ \\ \therefore J^{*} & = -\frac{\omega_0}{\lVert \omega \rVert}\end{align}$$

Given the following:

    $$ H(y) = - y \log(y) - (1 - y) \log(1 - y) $$

  2. The cross-entropy between the true label $y$ and the predicted probability $\hat{y}$ for class 1 is defined as:
    $$ H(y, \hat{y}) = - y \log(\hat{y}) - (1 - y) \log(1 - \hat{y}) $$

(a) Explain the concept of entropy in the context of binary classification. What does the entropy of the true label $y$ represent?

(b) Explain the difference between entropy and cross-entropy in binary classification. Why is cross-entropy used as the loss function in machine learning models instead of entropy?

(c) Given a single data point with a true label $y = 1$ and a predicted probability $\hat{y} = 0.8$ for class 1, calculate the cross-entropy loss for this prediction.

Solution

(a) In the context of binary classification, entropy represents the uncertainty or unpredictability of a random variable. For binary classification, the entropy of the true label $y$ can be interpreted as the amount of uncertainty or "information" contained in the label.

  • When $y$ is close to 0 or 1 (i.e., we are highly certain about the class), the entropy is low.
  • When $y$ is close to 0.5 (i.e., we are uncertain about the class), the entropy is high.

In general, entropy measures the uncertainty in the distribution of $y$ over the two classes. If the outcome is highly predictable (e.g., if $y$ is always 0 or always 1), the entropy will be low. If both classes are equally likely, the entropy is maximized, meaning there is high uncertainty.


(b)

Entropy represents the inherent uncertainty in the true label distribution. However, when training a machine learning model, we care not only about the true label but also about how well our predicted probabilities match the true labels.

Cross-entropy measures the difference between the true label distribution $y$ and the predicted probability distribution $\hat{y}$. It quantifies how "close" the model's predictions are to the true labels. Cross-entropy is a combination of both the true distribution's entropy and the divergence (difference) between the predicted and true distributions.

We use cross-entropy as the loss function in machine learning models because it directly measures how well the predicted probabilities match the true labels. Minimizing cross-entropy encourages the model to make predictions that are as close as possible to the true distribution.

(c)

Given:

  • True label: $y = 1$
  • Predicted probability for class 1: $\hat{y} = 0.8$

The cross-entropy loss is calculated as:

$$ H(y, \hat{y}) = - y \log(\hat{y}) - (1 - y) \log(1 - \hat{y}) $$

$$ H(1, 0.8) = - 1 \cdot \log(0.8) - (1 - 1) \cdot \log(1 - 0.8) = 0.223 $$


(d)

Minimizing the cross-entropy loss helps the model make better predictions by pushing the predicted probabilities $\hat{y}$ closer to the true label $y$. The cross-entropy loss becomes smaller as the predicted probability $\hat{y}$ approaches the true label $y$.

  • When $\hat{y}$ is very close to 1 (and $y = 1$), the loss approaches 0, meaning the model is highly confident and correct.
  • When $\hat{y}$ is very close to 0 (and $y = 1$), the loss becomes large, indicating the model is highly confident but wrong.

By minimizing the cross-entropy loss, the model adjusts its parameters to make predictions that maximize the likelihood of the true class being predicted with high confidence.

Problem 6¶

In deep ANNs, the vanishing gradient problem can cause learning to slow down significantly during backpropagation. Consider a network with $L$ layers where the activation function is ReLU, and all dense layers have weights initialized with small random values.

Using the concept of gradients through layers, explain why the vanishing gradient problem occurs in deep ANNs even with the presence of ReLU as the activation function.

Solution

In deep ANNs, the vanishing gradient problem can cause learning to slow down significantly during backpropagation. Consider a network with $L$ layers where the activation function is ReLU, and all dense layers have weights initialized with small random values.

Using the concept of gradients through layers, explain why the vanishing gradient problem occurs in deep ANNs, even with the presence of ReLU as the activation function.

The vanishing gradient problem occurs when the gradients computed during backpropagation become very small as they are propagated through layers. This causes the weights in earlier layers (closer to the input) to receive very small updates, slowing down or completely halting the learning process. Here's why this happens even with ReLU activation:

  1. Backpropagation and Chain Rule: In backpropagation, the gradient of the loss $L$ with respect to the weights in each layer $l$ is computed using the chain rule. For an ANN, the gradient of the loss with respect to the weights in layer $l$ is:
    $$ \frac{\partial L}{\partial W_l} = \frac{\partial L}{\partial a_{l+1}} \cdot \frac{\partial a_{l+1}}{\partial z_l} \cdot \frac{\partial z_l}{\partial W_l} $$
    This means the gradient for each layer depends on the gradients from the subsequent layers. The issue arises when these gradients become very small as they are propagated back through the layers.

  2. ReLU's Role: ReLU (Rectified Linear Unit) is a commonly used activation function because it helps mitigate the vanishing gradient problem to some extent, compared to activation functions like sigmoid or tanh, which have gradients less than 1 over most of their domain.

    The derivative of the ReLU function is:
    $$ f'(z) = \begin{cases} 1 & \text{if } z > 0 \\ 0 & \text{if } z \leq 0 \end{cases} $$
    For positive inputs, ReLU has a gradient of 1, allowing gradients to flow back without shrinking. However, if the input to a ReLU neuron is negative, the gradient is 0. This means that neurons with negative inputs during the forward pass become "dead" and stop contributing to the learning process. Once a neuron is dead, it does not get updated during training because the gradient remains zero.

  3. Small Weight Initialization and Deep Networks: Even with ReLU, if the weights are initialized with small random values, the pre-activation $z_l = W_l a_{l-1} + b_l$ may frequently end up being negative. In deep networks, where there are many layers, the accumulation of small weights and small activations from previous layers can lead to a large number of neurons receiving negative inputs and becoming inactive (i.e., outputting zero gradients).

  4. Gradients Shrinking Through Layers: Although ReLU prevents gradient values from shrinking when the input is positive (since the derivative is 1), the backpropagated gradients still depend on the weight matrices $W_l$ from all preceding layers. If these weight matrices have small values, the gradients still shrink through multiplication in the chain rule, even for neurons that are active. This means that despite the positive effect of ReLU, the vanishing gradient problem can still persist due to small weight initializations in deep networks.

The vanishing gradient problem can still occur in deep ANNs with ReLU activation because:

  • Neurons with negative pre-activations output zero gradients, causing them to stop learning (dead neurons).
  • Even when neurons are active, the multiplication of small weight matrices during backpropagation can lead to shrinking gradients as they pass through many layers.

Thus, while ReLU mitigates the vanishing gradient problem compared to other activation functions, it doesn't completely eliminate it, especially when weights are initialized with small random values or in networks with many layers.

Problem 10¶

Max-pooling layers are commonly used in CNNs to reduce the spatial dimensions of the input. Consider a max-pooling layer with a $2 \times 2$ window and stride 2.

Derive the gradient with respect to the input of the max-pooling layer during backpropagation. How does this gradient propagate, considering that only the maximum values in each window affect the output?

Solution:

Restating the Problem: We are asked to derive the gradient of the loss with respect to the input of a max-pooling layer during backpropagation. The max-pooling layer has a $2 \times 2$ window with stride 2, which reduces the spatial dimensions by selecting the maximum value from each window.

  1. Max-Pooling Forward Pass:

    During the forward pass, max-pooling selects the maximum value within each window of size $2 \times 2$. Let's denote the input to the pooling layer as $X$, where each window contains four values from the input:

    $$ X = \begin{bmatrix} x_{11} & x_{12} \\ x_{21} & x_{22} \end{bmatrix} $$
    The max-pooling operation selects the maximum value from this window. Suppose the maximum value is $x_{12}$, then the output $Y$ from this window would be:

    $$ Y = x_{12} $$

  2. Backpropagation through Max-Pooling:

    In backpropagation, we need to propagate the gradient of the loss $L$ back to the input $X$. Denote the gradient of the loss with respect to the output $Y$ as $\frac{\partial L}{\partial Y}$. Since max-pooling is not a learnable operation, we only propagate gradients, without modifying any parameters.

    For the gradient to propagate back through the max-pooling operation, we must assign the entire gradient $\frac{\partial L}{\partial Y}$ to the position of the input that was the maximum in the forward pass, and zero elsewhere. Mathematically, this is represented as:

    $$ \frac{\partial L}{\partial x_{ij}} = \begin{cases} 1, & \text{if } x_{ij} = \max(X) \\ 0, & \text{otherwise} \end{cases} $$

    This means that the gradient is passed back only to the element of the input that was the maximum during the forward pass.

  3. Example:

    Suppose in a $2 \times 2$ max-pooling window, the maximum value is $x_{12}$. The gradient of the loss, $\frac{\partial L}{\partial Y}$, will only propagate to $x_{12}$, and all other elements ($x_{11}$, $x_{21}$, and $x_{22}$) will receive a gradient of 0:

    $$ \frac{\partial L}{\partial X} = \begin{bmatrix} 0 & 1 \\ 0 & 0 \end{bmatrix} $$

Conclusion:¶

  • The gradient is propagated back only to the input element that had the maximum value in the forward pass.
  • Other elements in the pooling window will receive a gradient of zero.
  • This selective propagation of the gradient ensures that only the maximum values influence the subsequent weight updates, which aligns with the forward pass behavior of max-pooling.

Limitation of CAM:

One key limitation of Class Activation Maps (CAM) is that it requires modifications to the architecture of the neural network. Specifically, CAM requires:

  • The use of Global Average Pooling (GAP) before the final output layer.
  • The removal of fully connected (dense) layers, which are typically used in many networks.

This means that CAM cannot be applied to arbitrary pre-trained networks without architectural changes, which may not always be feasible or desirable, especially for networks that already have fully connected layers and do not use GAP.

Additionally, CAM relies on a linear combination of the feature maps from the final convolutional layer, which assumes that the relationship between the feature maps and the class score is linear. This may oversimplify how different regions of the image contribute to the final prediction, especially for complex non-linear models.

How Grad-CAM Addresses This Issue:

Grad-CAM (Gradient-weighted Class Activation Mapping) overcomes the limitations of CAM in several ways:

  1. No Architectural Changes Required: Unlike CAM, Grad-CAM does not require modifying the network architecture. It works with any pre-trained CNN architecture, including those that use fully connected layers after the convolutional layers. This makes Grad-CAM more flexible, as it can be applied to a wide variety of models without altering their structure.

  2. Uses Gradients to Weigh Feature Maps: Instead of relying on the final fully connected layer's weights, Grad-CAM uses the gradients of the class score with respect to the feature maps to determine which parts of the image are important for the class prediction. The importance of each feature map is determined by the gradients, which capture how sensitive the class score is to changes in the feature maps.

  3. Grad-CAM Formula: The Grad-CAM heatmap for class $k$ is computed using the following equation:
    $$ \text{Grad-CAM}_k(x, y) = \text{ReLU}\left( \sum_c \alpha_k^c F_c(x, y) \right) $$
    Where:

    • $ F_c(x, y) $ is the feature map activation at position $ (x, y) $ for channel $ c $.

    • $ \alpha_k^c $ is the weight for channel $ c $ and class $ k $, calculated as the global average of the gradients of the class score with respect to the feature map $ F_c $:

      $$ \alpha_k^c = \frac{1}{H \times W} \sum_{x=1}^{H} \sum_{y=1}^{W} \frac{\partial S_k}{\partial F_c(x, y)} $$

    • $ S_k $ is the score for class $ k $.

    • ReLU ensures that only positive contributions are considered (as negative gradients might indicate suppression of the class).

  4. Interpretation of Grad-CAM: Grad-CAM provides a more robust and general way of visualizing class-specific activations because it accounts for both the activation values and the gradients that indicate how much a particular feature map influences the class prediction. This allows Grad-CAM to capture more complex relationships between the feature maps and the final class score.

Grad-CAM addresses the limitations of CAM by:

  • Working with any pre-trained CNN architecture without requiring modifications.
  • Using gradients to capture non-linear relationships between feature maps and the class score.
  • Offering a more flexible and general approach to visualizing important regions for class predictions in complex networks.
